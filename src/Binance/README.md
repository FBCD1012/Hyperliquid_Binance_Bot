# 多币种K线成交量监控程序

## 🚀 功能特点

- 实时监控多个币种的5分钟K线数据
- 自动分析成交量变化（与30根K线均值对比）
- 智能分类成交量水平（正常/放量/缩量）
- 交互式控制台，动态添加/移除监控币种
- 支持批量添加热门币种

## 📋 使用方法

### 启动程序
```bash
node tradingVolume.js
```

### 控制台命令
1. **添加监控币种** - 输入任意USDT交易对
2. **移除监控币种** - 停止监控指定币种  
3. **查看当前监控列表** - 显示所有正在监控的币种
4. **查看热门币种列表** - 显示预设的热门币种
5. **批量添加热门币种** - 快速添加多个热门币种
6. **清空所有监控** - 停止所有监控
7. **退出程序**

### 使用示例
```
🎯 请输入命令编号 (1-7): 1
💰 请输入币种名称 (如: BTCUSDT): BTCUSDT

🎯 请输入命令编号 (1-7): 5
🎯 请输入要添加的币种编号 (用逗号分隔，如: 1,2,3): 1,2,3
```

### 输出格式
```
🚨 BTCUSDT | 2025/8/8 11:20:00 | 价格: 95234.5 (📈2.1%) | 成交量: 轻微放量 (15.3%)
```

## ⚙️ 配置说明

- **代理设置**: `CONFIG.proxy = 'http://127.0.0.1:7897'`
- **K线间隔**: 5分钟
- **历史数据**: 30根K线用于计算均值
- **自动重连**: WebSocket断线自动重连

## 🎯 成交量分类标准

- **异常放量**: >50%
- **明显放量**: 20-50%  
- **轻微放量**: 10-20%
- **正常**: -5% 到 10%
- **轻微缩量**: -15% 到 -5%
- **明显缩量**: -30% 到 -15%
- **异常缩量**: <-30%
