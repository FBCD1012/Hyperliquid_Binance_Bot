# 价格和成交量报警系统

## 功能概述

这个系统现在不仅检测买入量放量，还会检测价格变化，确保只在价格上升时进行报警。这样可以避免在价格下跌时误报，只关注真正的上涨趋势。

## 主要特性

### 1. 价格变化检测
- ✅ 只检测价格上升的情况
- ✅ 价格下降时不会报警
- ✅ 可配置价格上升阈值
- ✅ 显示具体的价格变化数值和百分比

### 2. 买入量放量检测
- ✅ 检测连续两根K线的买入量放量
- ✅ 可配置放量阈值
- ✅ 综合评级系统（大幅放量、极度放量、超级放量）

### 3. 双重条件验证
- ✅ 必须同时满足：价格上升 + 买入量放量
- ✅ 避免假信号，提高报警质量

## 配置选项

在 `tradingVolume.js` 文件顶部可以修改以下配置：

```javascript
const TRADING_CONFIG = {
    // 价格变化阈值：只有当价格上升超过这个百分比时才报警
    // 设置为0表示只要价格上升就报警
    // 设置为1.0表示价格需要上升超过1%才报警
    MIN_PRICE_INCREASE_PERCENT: 0.0,
    
    // 买入量放量阈值：只有当买入量超过平均值的这个百分比时才报警
    // 设置为200.0表示买入量需要超过平均值的200%才报警
    MIN_VOLUME_INCREASE_PERCENT: 200.0
};
```

## 报警条件

系统只会在以下**所有条件**都满足时才发送报警：

1. **价格条件**：第二根K线收盘价 > 第一根K线收盘价
2. **价格阈值**：价格上升百分比 ≥ `MIN_PRICE_INCREASE_PERCENT`
3. **成交量条件**：两根K线都出现买入量放量
4. **放量阈值**：买入量超过平均值的 `MIN_VOLUME_INCREASE_PERCENT`%

## 报警信息

每次报警会包含以下信息：

### 价格信息
- 第一根K线收盘价
- 第二根K线收盘价
- 价格变化绝对值
- 价格变化百分比

### 成交量信息
- 两根K线的买入量数据
- 放量程度和评级
- 综合放量指标

### 币种信息
- 合约上线时间
- 当前持仓量
- 持仓总价值

## 使用建议

### 保守策略
```javascript
MIN_PRICE_INCREASE_PERCENT: 1.0,    // 价格上升超过1%
MIN_VOLUME_INCREASE_PERCENT: 300.0  // 买入量超过平均值300%
```

### 激进策略
```javascript
MIN_PRICE_INCREASE_PERCENT: 0.0,    // 任何价格上升
MIN_VOLUME_INCREASE_PERCENT: 200.0  // 买入量超过平均值200%
```

### 平衡策略
```javascript
MIN_PRICE_INCREASE_PERCENT: 0.5,    // 价格上升超过0.5%
MIN_VOLUME_INCREASE_PERCENT: 250.0  // 买入量超过平均值250%
```

## 注意事项

1. **避免误报**：系统现在只在价格上升时报警，减少了假信号
2. **可配置性**：可以根据市场情况调整阈值
3. **双重验证**：价格和成交量必须同时满足条件
4. **实时监控**：基于5分钟K线数据，实时检测市场变化

## 技术实现

- 使用WebSocket实时接收Binance K线数据
- 5分钟K线周期，确保数据准确性
- 30根K线历史数据，计算可靠的均值
- Telegram机器人推送，支持消息去重和限速
